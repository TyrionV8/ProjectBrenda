# ProjectBrenda
 A Full Simple TowerDefence
...
Not so simple yet

Bugs crawl over a circuit board and you defend the CPU with turrets.

## Godot version (active)

The game is being continued in **Godot 4.5** in [`godot/`](godot/) — open
`godot/project.godot` in the editor. See [`godot/README.md`](godot/README.md)
for the layout, data files, tests and exporting.
